# TARGET-X
### *From Broadcast Pixels to Tactical Intelligence*
> **AI-Powered Football Player, Referee, and Ball Tracking & Tactical Intelligence**  
> Developed for **VISIONX: FROM PIXELS TO PROTOTYPE** One-Day Hackathon  
> Organized by **Bannari Amman Institute of Technology** (Computer Vision & Image Processing Community)

---

## 1. Executive Summary

**TARGET-X** is an authentic, locally executed computer-vision system that ingests football broadcast match video and converts unstructured pixel data into structured tactical intelligence.

```
Football Broadcast Video
        ↓
Authentic AI Detection (Player, Referee, Ball)
        ↓
Persistent Multi-Object Tracking (Player #01, #02...)
        ↓
Dynamic Team Discovery (CIE LAB Unsupervised KMeans)
        ↓
Goalkeeper Association Engine
        ↓
Confidence-Based Team/Country Identity
        ↓
Movement Trajectories & 2D Tactical Pitch Radar
        ↓
Gaussian Spatial Heatmaps & Tactical Spread Analytics
```

## 4. Key Innovations & Technical Modules

### A. Dynamic Team Discovery (Not Hardcoded)
- Upper-body / torso crop (15% to 55% of player bounding box).
- HSV grass masking ($H \in [35, 85]$) eliminates pitch green background noise.
- Unsupervised KMeans clustering ($k=2$) in CIE LAB color space groups outfield players dynamically into Team 1 and Team 2 without hardcoded color assumptions.

### B. Goalkeeper Association Engine
- Goalkeepers wear distinct kits (e.g., green, dark blue) that differ from their outfield teammates.
- Instead of creating a false "3rd or 4th team", TARGET-X detects kit outliers situated in goal defense areas and associates each goalkeeper with Team 1 or Team 2 based on defensive field proximity.

### C. Referee Isolation
- Match officials are detected via dedicated Class 1 and isolated as `Referee #01` with an iconic yellow badge, strictly excluded from team clusters.

### D. Ball Tracking & Missing-Frame Handling
- Small footballs ($10 \times 10$ pixels) are tracked with dedicated trajectory trails.
- When the ball is occluded or out of frame, the system explicitly reports missing status—**never fabricating false ball positions**.

### E. Tracked Image-Space Tactical View
- Projects player coordinates to an interactive 2D top-down football pitch radar.
- Computes tactical centroids and spatial compactness spreads.
- In strict adherence to compliance rules, designated as *Tracked Image-Space Tactical View* rather than uncalibrated physical meters.

### F. Team & Country Identity Intelligence
- Compares extracted kit palettes against `data/teams.json`.
- Outputs confidence-based identity (`HIGH`, `MEDIUM`, `LOW`, `UNKNOWN`).
- If evidence is insufficient, reports **"Country: Unknown (Insufficient visual evidence)"** rather than fabricating nationality.

## 5. Quickstart & Installation

### Option A: Windows 11 (PowerShell)
```powershell
# 1. Automated Setup (Installs Python venv, packages, frontend, and trains model)
.\scripts\setup.ps1

# 2. Start Backend (Terminal 1)
.\scripts\start_backend.ps1

# 3. Start Frontend (Terminal 2)
.\scripts\start_frontend.ps1
```

### Option B: macOS / Linux (Bash)
```bash
# 1. Automated Setup
./scripts/setup.sh

# 2. Start Backend (Terminal 1)
./scripts/start_backend.sh

# 3. Start Frontend (Terminal 2)
./scripts/start_frontend.sh
```

Open your browser to: **`http://localhost:5173`**

## 6. Video Input & Demo Mode

The primary demo video is expected at:
```
data/demo/football_demo.mp4
```

1. **One-Click DEMO MODE**: Click **Run Demo Mode** on the dashboard header to run the genuine pipeline on `data/demo/football_demo.mp4`.
2. **Video Upload**: Click **Upload Match** to upload any compatible `.mp4`, `.mov`, `.m4v`, or `.avi` broadcast football video (up to 200MB).
3. **Automated Benchmark**: If no video has been placed in `data/demo/` yet, the system automatically creates an authentic benchmark clip (`cv/demo_generator.py`) so the pipeline can be validated immediately.

## 7. Model Training & Evaluation Commands

To run local training and generate genuine metrics:
```bash
# Activate virtual environment
source venv/bin/activate   # or .\venv\Scripts\Activate.ps1 on Windows

# Run training from scratch (saves models/targetx_detector.pt & training_curves.png)
python training/train.py

# Run validation evaluation (saves metrics.json & confusion_matrix.png)
python training/evaluate.py
```
